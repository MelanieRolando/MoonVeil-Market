# MoonVeil Market

MoonVeil Market es una tienda online ficticia orientada a gamers, donde se pueden encontrar videojuegos, accesorios, coleccionables y ropa con una estética cozy y pastel.

El proyecto fue realizado como parte de la Pre-Entrega del curso de Front End.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts
- Font Awesome
- Formspree

## Características

- Diseño responsive para diferentes tamaños de pantalla.
- Navegación interna entre las distintas secciones.
- Catálogo de productos.
- Sección de reseñas.
- Formulario de contacto funcional.
- Enlaces de contacto a Email, WhatsApp y Behance.

## Estructura del proyecto

- `index.html` — estructura principal del sitio.
- `css/styles.css` — estilos y diseño responsive.
- `img/` — imágenes utilizadas en el proyecto.
